## Description
GradePortfolio est un portfolio personnel conçu et développé par **Peterley Auguste**, graphiste et designer freelance.  
Il met en avant des projets créatifs, des badges personnalisés, et une interface optimisée pour la collaboration à distance et la présentation auprès des recruteurs.

## 🚀 Technologies utilisées
- **HTML5 / CSS3**
- **Tailwind CSS** (migration depuis custom CSS)
- **JavaScript** (animations et interactions)
- **GitHub Pages** pour le déploiement

## Versioning
Le projet suit une logique de versioning sémantique (**MAJOR.MINOR.PATCH**) :
- **MAJOR** : changements majeurs (refonte complète, nouvelle architecture).  
- **MINOR** : nouvelles fonctionnalités ou sections ajoutées.  
- **PATCH** : corrections de bugs ou ajustements mineurs.  

### Versions récentes
- **2.0.0** : Migration complète vers Tailwind CSS.  
- **2.0.1** : Correction des chemins de fichiers (images, PDF).
